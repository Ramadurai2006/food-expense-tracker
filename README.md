# Food Expense Tracker

A Python project to manage food expenses.

## Features
- Add food expenses
- View expense data
- Store data using JSON
- Menu-driven program

## Technologies Used
- Python
- JSON

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python expense_tracker.py
```
